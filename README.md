# CamLock — ตู้เช่ากล้องอัตโนมัติ (Firmware)

เฟิร์มแวร์ ESP32 สำหรับตู้เช่ากล้องอัตโนมัติ ที่ให้นักศึกษายืมกล้องได้ด้วยตัวเองตลอด 24 ชั่วโมง
โดยไม่ต้องมีเจ้าหน้าที่ และผู้ดูแลตรวจสอบได้ตลอดว่าใครเปิดช่องไหน เมื่อไร

> **วิชา CPE23367 · มหาวิทยาลัยศรีปทุม**

---

## ปัญหาที่แก้

ห้องแล็บให้ยืมกล้องด้วยสมุดจดและกุญแจ ทำให้เกิดปัญหาสามข้อ

1. ยืมได้เฉพาะเวลาที่มีเจ้าหน้าที่อยู่
2. ไม่รู้ว่าใครถือกุญแจอยู่ตอนนี้
3. กล้องหายแล้วย้อนหาคนรับผิดชอบไม่ได้

CamLock เปลี่ยนให้เป็นตู้ที่ปลดล็อกด้วย QR จากแอป บันทึกทุกการเปิดขึ้นคลาวด์ และรู้สถานะประตูแบบเรียลไทม์


## ฮาร์ดแวร์

บอร์ดออกแบบเอง **100 × 80 มม. สองชั้น** อุปกรณ์ 44 ตัว ผลิตที่ JLCPCB

| ส่วน | อุปกรณ์ |
|---|---|
| ตัวประมวลผล | ESP32-WROOM-32E (Flash 4MB) |
| ภาคไฟ | DC 12V → K7805-1000R3 → 5V → AMS1117-3.3 → 3.3V |
| ขับกลอน | S8050 → รีเลย์ SRD-05VDC-SL-C → กลอนโซลินอยด์ 12V |
| อ่านประตู | รีดสวิตช์แม่เหล็ก แบบ NO |
| โปรแกรม | USB-C + CH340C พร้อมวงจรรีเซ็ตอัตโนมัติ |
| ป้องกัน | ฟิวส์ PTC 1.85A · ไดโอดกันขั้วกลับ · ไดโอดฟลายแบ็ก 2 จุด |

ดูผังอุปกรณ์ทั้งบอร์ดได้ที่ [`docs/CAMLOCK_board_guide.png`](docs/CAMLOCK_board_guide.png)

## ขา GPIO ที่ใช้

| ขา | ชื่อในวงจร | ทิศทาง | หน้าที่ |
|---|---|---|---|
| **GPIO26** | `RELAY_DRV` | OUTPUT | สั่งรีเลย์ · HIGH = กลอนเปิด |
| **GPIO27** | `DOOR_GPIO` | INPUT | รีดสวิตช์ · LOW = ประตูปิด |
| **GPIO25** | `STATUS` | OUTPUT | ไฟแสดงสถานะ |

---

## จุดต่อสายภายนอก

| คอนเนกเตอร์ | ต่อกับ |
|---|---|
| **J1** หรือ **J2** | ไฟเลี้ยง 12V (แจ็ค DC 5.5×2.1 มม. หรือเทอร์มินัล) |
| **J3** | กลอนไฟฟ้าโซลินอยด์ 12V |
| **J4** | รีดสวิตช์แม่เหล็กที่ขอบประตู |
| **USBC1** | สาย USB สำหรับอัปโหลดโค้ด |

## วิธีติดตั้งและใช้งาน

### 1. เตรียม Arduino IDE

ติดตั้งบอร์ด ESP32 ผ่าน Boards Manager แล้วเลือก **ESP32 Dev Module**

ไลบรารีที่ต้องมี

| ไลบรารี | ผู้พัฒนา |
|---|---|
| `PubSubClient` | Nick O'Leary |
| `ArduinoJson` | Benoit Blanchon |

### 2. ตั้งค่าใน `src/camlock/camlock.ino`

```cpp
const char* WIFI_SSID = "ชื่อ Wi-Fi";
const char* WIFI_PASS = "รหัส Wi-Fi";
const char* TB_HOST   = "thingsboard.cloud";
const char* TB_TOKEN  = "Access Token ของ device";
const char* LOCKER_ID = "A";
```

> ⚠️ **อย่า commit Access Token จริงขึ้น repo** ให้แก้เฉพาะในเครื่องตัวเอง
> ถ้าเผลอ push ขึ้นไปแล้ว ให้เข้า ThingsBoard สร้าง token ใหม่ทันที

### 3. อัปโหลด

ต่อสาย USB-C เข้ากับบอร์ด แล้วกด Upload ได้เลย
บอร์ดมีวงจรรีเซ็ตอัตโนมัติ (Q2 Q3) ไม่ต้องกดปุ่ม BOOT ค้าง

## ตั้งค่า ThingsBoard

1. สร้าง Device ใหม่ แล้วคัดลอก **Access Token**
2. เพิ่มวิดเจ็ตบนแดชบอร์ด แล้วผูกกับ RPC method ด้านล่าง

### คำสั่ง RPC

**เปิดกลอน**

```json
{ "method": "openLocker", "params": { "ms": 3000 } }
```

ค่า `ms` จำกัดไว้ที่ 500–10000 มิลลิวินาที เพื่อกันคอยล์รีเลย์ร้อนเกิน
ถ้าไม่ส่งมา จะใช้ค่าเริ่มต้น 3000 มิลลิวินาที

ตอบกลับ

```json
{ "ok": true, "ms": 3000 }
```

**อ่านสถานะ**

```json
{ "method": "getStatus" }
```

ตอบกลับ

```json
{ "doorOpen": false, "lockActive": false }
```

### Telemetry ที่ส่งขึ้นคลาวด์

ส่งทุก 10 วินาที และส่งทันทีเมื่อสถานะประตูเปลี่ยน

| ฟิลด์ | ชนิด | ความหมาย |
|---|---|---|
| `doorOpen` | boolean | ประตูเปิดอยู่หรือไม่ |
| `lockActive` | boolean | กลอนกำลังทำงานอยู่หรือไม่ |
| `rssi` | int | ความแรงสัญญาณ Wi-Fi (dBm) |
| `uptime` | int | เวลาที่บอร์ดทำงานมาแล้ว (วินาที) |
| `unlockCount` | int | จำนวนครั้งที่ปลดล็อกสะสม |

### Attributes

ส่งครั้งเดียวตอนเชื่อมต่อสำเร็จ: `lockerId` · `firmware` · `ip`

## ความปลอดภัยในการออกแบบ

- **ตั้ง `RELAY_PIN` เป็น LOW ก่อนเสมอตอนบูต** เพื่อกันกลอนเปิดเองตอนไฟกระพริบ
- **R1 10kΩ ดึงขา IO26 ลงกราวด์** กันขาลอยช่วงที่ ESP32 ยังไม่บูตเสร็จ
- **รีเลย์แยกวงจร** ไฟ 12V ของกลอนไม่มีทางแตะวงจร 3.3V ของ ESP32
- **ไดโอดฟลายแบ็ก 2 จุด** D2 ที่คอยล์รีเลย์ และ D3 ที่กลอน กันไฟย้อนกลับทำลายหน้าสัมผัส
- **จำกัดเวลาเปิดกลอนที่ 10 วินาที** ไม่ว่าคำสั่งจะส่งค่ามาเท่าไร
